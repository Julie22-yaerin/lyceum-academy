## Cấu trúc mỗi micro-node

Mỗi node đúng 1 tình huống, gồm: **dấu hiệu chính xác → nguyên nhân gốc → làm ngay (60-90s) → câu nói mẫu → bẫy phải tránh → drill 60s**. Đủ để bóc ra dùng ngay khi đang chảy máu, không cần học lại lý thuyết.

Muốn thêm node? Copy template từ bất kỳ node nào, thêm 1 dòng vào bảng trên. Node gốc lý thuyết nằm ở `05 - Skills` / `04 - Concepts`.

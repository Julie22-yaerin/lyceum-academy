# 🏛️ The Lyceum — Curriculum Second Brain

A structured knowledge base for **Mathematics & Sciences** across **IGCSE, GCSE, A-Level, IB, and AP**.
Built for AI agents to retrieve accurate, source-linked study material per syllabus topic.

## How this vault is organised
```
The Lyceum - Second Brain/
├── 00 - START HERE.md          ← you are here
├── 01 - IGCSE/                 ← Cambridge (CIE) + Edexcel International
├── 02 - GCSE/                  ← AQA (UK)
├── 03 - A-Level/               ← Cambridge (CIE) AS & A Level
├── 04 - IB/                    ← IB Diploma (SL/HL, concept-based science guides)
├── 05 - AP/                    ← Advanced Placement (College Board)
└── 99 - Resources Hub/         ← shared past-paper + revision sources
```
Each **subject folder** contains:
- `_Subject Overview.md` — syllabus code, assessment structure, topic map
- one **file per syllabus topic** — official reference + curated resources + past papers

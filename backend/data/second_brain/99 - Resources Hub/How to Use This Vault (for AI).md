# How to Use This Vault (for AI agents)

## Retrieval logic
1. Identify **level** (IGCSE / GCSE / A-Level) and **board** from the query.
2. Open the matching `01/02/03` folder → subject folder → `_Subject Overview.md`.
3. Jump to the specific **topic note** for granular objectives, resources, and past papers.

## What each topic note guarantees
- A link to the **official syllabus/specification** (authoritative content list & command words).
- 2–4 **curated study resources** (textbook-grade or exam-board-aligned).
- A **past paper + mark scheme** entry point.
- A `Notes for AI` block for definitions, formulae, and common misconceptions.

## Trust hierarchy for sources
1. **Exam board** (Cambridge International, Pearson Edexcel, AQA) — always primary.
2. **Board-endorsed textbooks** and official learner guides.
3. **Curated third-party** (Save My Exams, Physics & Maths Tutor, ZNotes, Corbettmaths) — good for revision, verify against spec.
4. Never treat forum/AI-generated summaries as authoritative without a board cross-check.

## Maintenance
- Syllabus codes rotate on multi-year cycles — re-verify the official page each September.
- When a spec changes, update `_Subject Overview.md` first, then affected topic notes.
